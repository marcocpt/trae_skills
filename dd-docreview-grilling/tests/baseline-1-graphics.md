# 基线测试 1：图形化解答要求

## 场景

用户触发文档审核，提供文档路径 `docs/design.md`，该文档描述了一个支付处理系统，包含多个模块交互。

用户提问："支付流程章节中，支付回调的状态流转是怎样的？"

## 预期行为（修改后技能）

1. AI 解答**必须包含至少一种图形化**（Mermaid 流程图/状态图/时序图/类图，或 HTML server）
2. 支付回调状态流转适合用 `stateDiagram-v2` 展示
3. 解答附代码/文档位置锚点

## 当前基线行为（修改前预期失败）

1. ❌ AI 用纯文字描述状态流转，无 Mermaid 图
2. ❌ 无图形化类型判断逻辑
3. ❌ 无 HTML server 启动机制

## 压力因素

- 状态流转涉及 5+ 个状态，纯文字描述难以理解
- 用户需要快速理解流程，文字箭头链（A→B→C）不如状态图直观
