# dd 共享风险分级审查规则

## 概述

本技能固定审查语义，但让执行强度随风险变化。质量标准不随宿主能力或 Token 预算下降。

本技能固定为 `invocation_mode=helper`：返回分角色结论和证据，不自行 Host Close。无子 Agent 时由调用方执行等价多视角复核；顶层会话结束遵循 [dd-shared-ask](../dd-shared-ask/SKILL.md)。

## 固定审查语义

所有检查必须覆盖：

1. 覆盖与范围；
2. 一致与正确；
3. 可验证与可观测。

| 方向 | 名称 | 核心关注 | 典型检查项 |
|------|------|----------|------------|
| **A** | 覆盖与范围 | 该有的有没有、范围对不对、是否混入未请求功能 | 完整性、范围、YAGNI、规格符合、AC 覆盖 |
| **B** | 一致与正确 | 互相矛盾吗、符合规范吗、结构一致吗 | 一致性、可计划性、CODING_STANDARDS、测试质量 |
| **C** | 可验证与可观测 | 能验证吗、UI 有真实证据吗 | 可验证性、真实入口、用户可见证据、内部状态误判 |

## 审查等级

| `review_level` | 执行方式 | 适用情况 |
|---|---|---|
| `low` | 主 Agent 一次完成三视角自检 | 机械迁移、链接修复、低风险格式变更 |
| `standard` | 一个独立 reviewer 完成三视角 | 普通文档产物和常规节点 |
| `high` | 三个方向 reviewer 并行，主 Agent 汇总 | Brownfield 基线、架构边界、兼容分类、高风险 UI/数据迁移 |

没有子 Agent 能力时，使用同一 Agent 的独立检查轮次替代。执行方式可以降级，检查项不得减少。

默认等级：

- 纯机械或局部低风险调整：`low`；
- 普通 writer 产物：`standard`；
- Brownfield 基线、架构/兼容决策、用户可见高风险行为：`high`。

项目规则、用户明确要求或调用方提供的 `review_level` 可以提高等级。不得仅因 Token 紧张降低已由风险确定的等级。

## 调度与汇总

1. `low`：主 Agent 按 A→B→C 顺序自检并记录结论；
2. `standard`：独立 reviewer 接收原始产物和三视角清单，不接收预设结论；
3. `high`：三个 reviewer 按 A/B/C 分工；涉及 UI 时三者都检查“是否把内部状态误当成 UI 证据”；
4. 任一 reviewer 可跨方向上报；
5. 结论冲突时按最严格结论处理；
6. 汇总分为“必须修复”“建议修复”“可选优化”。

## 处理结果

- blocker 和“必须修复”项自动修复并以同等级复验；
- 建议项只有涉及范围、产品语义、架构或高风险处置时 ASK；
- `low` 发现跨文档风险时升级到 `standard`；
- `standard` 出现冲突或兼容性争议时升级到 `high`；
- 同一检查最多重试 3 次，仍失败时按 `dd-shared-ask` 升级；
- 禁止为了省 Token 跳过确定性 lint、解析、链接、映射或测试检查。

## 被其他 skill 引用方式

各 dd 技能在检查类步骤中引用本技能，并传递 `review_level`。引用格式：`审查语义与执行等级遵循 [dd-shared-subagent](../dd-shared-subagent/SKILL.md)`
