# 每类测试的解释与概览格式

进入一类测试用例时，先输出以下三部分内容，再进入逐风险点 grilling。

## 1. 本类涉及的术语

只解释理解当前类别必需的术语。每个术语使用以下格式：

- `术语`：一句人话定义。
- 必要时增加一个很短的例子。

不要一次建立完整领域词典。

## 2. 这类测试是在做什么

用人话回答：

1. 这一类测试想防止什么错误？

回答必须基于实际测试代码，不得只复述测试函数名或源码。

## 3. 当前类别测试概览

逐条列出该类别的每个测试，格式为：

- 注释：用一两句人话说明该测试在验证什么、针对什么风险。
- 源码：直接给出该测试的完整源码（缩进在代码块中）。

```swift
// 说明：该测试验证登录失败时返回错误码，防止把失败误判为成功。
func testLoginFailureReturnsErrorCode() {
    let result = login(user: "u", password: "wrong")
    XCTAssertEqual(result.errorCode, .invalidCredentials)
}
```

这里只做事实概览（注释 + 每个测试源码），不在此处一次性输出全部风险点。完成概览后，进入逐风险点 grilling。
