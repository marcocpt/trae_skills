# 每类测试的解释与概览格式

进入一类测试用例时，先输出以下三部分内容，再进入逐风险点 grilling。

## 1. 本类涉及的术语

只解释理解当前类别必需的术语。每个术语使用以下格式：

- `术语`：一句人话定义。
- 必要时增加一个很短的例子。

不要一次建立完整领域词典。

## 2. 这类测试是在做什么

用人话回答：

1. 这一类测试想防止什么错误？
2. 测试向代码输入了什么？
3. 期望代码做出什么反应？
4. 如果没有这类测试，可能出现什么问题？
5. 当前测试实际覆盖到了什么？
6. 当前测试没有证明什么？

回答必须基于实际测试代码，不得只复述测试函数名或源码。第 5、6 问尤其要区分“已证明”与“未证明”。

## 3. 当前类别测试概览

简要列出（建议用表格）：

- 测试函数
- 测试场景
- 核心输入
- 关键断言
- 对应规则或需求
- 初步覆盖结论

这里只做事实概览，不在此处一次性输出全部风险点。完成概览后，进入逐风险点 grilling。
