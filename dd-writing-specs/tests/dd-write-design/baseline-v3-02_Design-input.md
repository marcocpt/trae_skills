# F3.2 模板匹配设计

## 模块划分

- 模板匹配模块：负责模板加载、匹配执行；
- 结果汇总模块：负责结果聚合与输出；
- 批量任务编排模块：负责批量任务调度。

## 职责边界

模板匹配模块不写文件；结果汇总模块不执行匹配；批量任务编排模块不解析模板内容。

## 数据流

输入图像与模板 → 模板匹配模块 → 原始匹配结果 → 结果汇总模块 → 报告文件。

## 状态变化

批量任务编排模块的任务状态：待处理 → 执行中 → 已完成 / 失败。

## 协作关系

批量任务编排模块调度模板匹配模块，模板匹配模块输出交给结果汇总模块。
