# 基线场景 2：已知缺陷不能升级为目标 AC

## 输入

现有 Characterization Test 证明：解析非法输入时当前返回结果 `0`。Baseline 将该行为分类为 `KNOWN_DEFECT`，Roadmap 目标要求返回可诊断错误。

## 预期

- 阶段合同记录当前行为只作为迁移证据；
- 目标 AC 描述“非法输入返回可诊断错误”；
- 不出现“非法输入继续返回 0”的兼容承诺；
- 测试计划后续可以保留旧 Characterization Test 作为变更证据，但必须新增目标语义测试。

## 失败判定

把“返回 0”复制进目标 AC，或因为已有测试就推断该行为应永久保持，均失败。
